# Host Provisioning

Encrypted host provisioner. Requires a password to decrypt.

## Usage

Linux / macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/mkembel33/pub/main/bootstrap.sh | bash
```

Windows 11 (elevated PowerShell):

```powershell
irm https://raw.githubusercontent.com/mkembel33/pub/main/bootstrap.ps1 | iex
```
